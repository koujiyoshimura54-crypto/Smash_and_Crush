## Actual hit calculation

The current service did not use a separate attack Part. It computed distance from a Boss-local X/Z rectangle, compared it to Reach plus Player radius, and separately checked vertical overlap and attack angle. Scaling Reach alone would also narrow the width; scaling only the body box would not reduce the complete hit depth by 10%.

For the existing bounds' local center `cz = (Low.Z + High.Z) / 2`, the distance test now uses:

```text
depthPoint = cz + (playerLocalZ - cz) / DepthScale
dx = unchanged distance to [Low.X, High.X]
dz = distance from depthPoint to [Low.Z, High.Z]
sqrt(dx^2 + dz^2) <= unchanged Reach + PlayerRadius
```

This compresses the complete rounded distance envelope along Boss-local Z about the original center, including the reach/radius extension. It preserves its lateral extent. The original angle predicate still uses actual positions, and the original height predicate still uses unscaled Y. Raw bounds, Part dimensions, Pivot, model sizes, physical movement, Player-to-Boss contact, damage and clocks are unchanged. Bounds are reconstructed from the original geometry each call; no geometry or previous scaled result is mutated.

Both Worlds and all Stages use this service. The World2 Stage1 SCP096 eligibility branch and the ordinary Boss branch both call the same IsInRange before actual Humanoid.Health subtraction. Their existing animation/cadence conditions remain intact.
